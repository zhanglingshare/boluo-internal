# 博罗内部决策风洞 V2：研究设计、证据版本、模型准入与可证伪规则

更新时间：2026-11-15
研究性质：**公开宏观事实 + 合成微观数据 + 条件敏感性研究工具**。本版本是可操作的科研原型，不是县域经济因果识别完成稿，不是博士论文实证成果，也不是官方预测。

## 0 研究问题

核心竞争解释：在2020–2025年GDP规模增加的同时，三次产业份额怎样变动？投资与工业信号为何背离？生产性服务是否在本地承接制造业扩张？产业网络节点、项目投产和技能约束之间的可检验机制是什么？

**要证伪而非默认正确的假设：**
- H1：GDP增长并不自动等于产业结构升级。
- H2：固定资产投资同比下降并不必然导致当年工业增加值同比下降；存在存量产能、建设投产时滞、价格与外需竞争解释。
- H3：工业产出提升并不自动意味着本地生产性服务价值留存提升。
- H4：1:5:4三产结构比例不是未经检验即可确定的最优结构。

这些假设当前被编码为可查看的竞争性解释。由于缺乏真实的企业采购、项目逐期兑现、价格、技能就业和服务外溢数据，当前**不能**完成各假说的因果识别。

## 2 理论结构与变量

理论链：
1. 外部需求、价格、资本投入、技能等共同决定县域产业状态。
2. 项目兑现、制造业产出与本地专业服务承接形成待检验的传导机制。
3. 供应链关系形成潜在的集中依赖与断点风险。
4. 三次产业增加值由统一统计核算；经营调查路径系数与GDP没有天然乘法映射。

前端变量字典：在 research-core.js 的 VARIABLES 中逐变量记录ID、定义、理论角色、测量单位、期间、证据等级、观测状态、潜在口径错误。路径由 DAG 数组记录，界面点击节点可查变量说明。当前 DAG 是待检验**机制图**，并未经过因果识别，不能将箭头理解为已证实的政策作用方向。

后续真实变量筛选必须完成：操作定义 → 指标有效性 → 时间顺序 → 混杂和共同冲击 → 数据缺失与噪声 → 多重共线性 → 预测或识别验证 → 替代机制。只凭六期宏观数据不能估计十多个参数。

## 3 模型与输出责任边界

| 模型 | 当前计算 | 不能得出的结论 |
|---|---|---|
| 历史描述 | 2020–2025结构份额、HHI、现价算术增量、修订标记 | 精确的实际增速贡献、因果机制 |
| 条件MC | 从2025三产现价基准，用C级年增长和相关冲击模拟P10/P50/P90及目标命中频率 | 真实2030目标达成概率 |
| 双条件响应面 | 81个工业/服务条件组合，以无随机冲击复利计算总量并可点击反推参数 | 历史估计出的政策交互因果效应 |
| 产业网络 | 500合成主体、680合成有向边；按合成采购额或固定种子随机删除若干服务主体 | 博罗实际企业连接、实际经济损失 |
| 问卷路径 | 300份默认合成Likert问卷，探索性Mode-A PLS路径与120次Bootstrap、Alpha和AVE | 已验证SmartPLS等价性、可折算GDP的因果系数 |
| 模型对照 | MC中位数、7.3%三产共同增速、2020–2023三产名义外推、无冲击固定增长 | 模型分歧 = 统计置信区间；对模型主观加权后的预测概率 |
| 极短回测 | 2022、2023两个滚动留出年，两类简单名义增长基准的绝对百分比误差 | 对2025起点MC机制的样本外认证 |

## 4 可复现与不确定性

- 默认宏观2025基准、情景与种子存于浏览器；参数变化立即重新算，不是渲染静态假图。
- 同条件、同种子、同代码版本应得相同结果；GitHub Actions执行语法、数据检查、运行时模拟浏览器与结构图测试。
- 模拟P10/P90反映**模型条件内随机扰动的不确定性**；参数、数据修订、模型选择属于另一层**认知不确定性**，不能混成一个概率带。
- 弱模型或短样本暴露在UI而非隐藏。未来接入真实微观样本、价格口径和更长时间序列后，必须重新标定，而非沿用合成数据生成时的系数。
- 保存研究条件在 localStorage，**非服务器审计级不可更改档案**。导入与导出本阶段后置。

## 6 研究质量闸门（下一次升级前必须回答）

1. 2024修订后的三产最终分项从哪里取得？若缺失，是否清楚提示跨版本口径？
2. 模拟的三产年名义增长率能否来自更长真实历史的分行业估计？受价格、行业周期影响多大？
3. 变量选择是否发生了过拟合/后见之明？显著性与预测性有无区别？
4. 产业网络主体、供需边、边方向和属地是否可被实际观察？未观察部分怎么处理？
5. 探索性PLS与SmartPLS在题项预处理、估计步骤、bootstrap、HTMT、VIF和PLSpredict方面差异如何？
6. 目标结构和GDP阈值是否通过决策者界定，真实机会成本和就业/收入收益是否有可核验指标？
7. 模型分歧在外部冲击下是否稳定？新一年统计公布后应怎样重新回测？
