# V6 数据接入与主动问题发现协议

## 1. 当前定位

V6不是自动替部门下结论的AI，也不是实时监控系统。它是一个本地运行的证据筛查器：把公开指标、已有结构数据和经授权导入的匿名汇总观察放在一起，生成“值得核查的问题候选”。

V6目前不上传数据、不连接部门数据库、不自动抓取互联网。公开数据仍来自仓库已记录的来源；新增CSV只保存在当前浏览器的localStorage。浏览器本地存储不是加密保险箱，不应导入个人信息、企业商业秘密、原始交易明细或可识别个人的问卷行数据。

## 2. 可导入的数据

只接受两种聚合记录：

- `metric`：一个地区、行业、期次、统计范围下的单项数值。
- `survey_aggregate`：问卷结果的匿名汇总值，必须同时提供样本量、目标总体、抽样框、聚合方法和缺失率。

不接受个人级问卷答卷、员工名单、供应商交易明细或包含身份字段的数据。企业调查应先在可信环境中完成脱敏和聚合，再导入汇总表。

## 3. CSV字段

必需字段：

| 字段 | 含义 |
|---|---|
| record_type | metric 或 survey_aggregate |
| indicator | 指标/题项名称 |
| period | YYYY、YYYY-MM、YYYY-MM-DD 或 YYYYQ1 |
| geography | 地区范围，例如博罗县 |
| value | 数值 |
| unit | 单位，例如%、亿元、分 |
| scope | 统计范围、分母或口径说明 |
| source_name | 来源名称 |
| evidence_grade | A/B/C/D |

可选字段：

- `industry`：行业分类。
- `source_url`：公开来源链接，只接受http/https。
- `notes`：口径或边界说明。

`survey_aggregate`额外必需：

- `sample_n`：样本量。
- `population`：目标总体。
- `sample_frame`：抽样框及覆盖范围。
- `aggregation`：mean / median / share / count。
- `missing_rate`：缺失率，0—100。

证据等级：A为官方或可核验原始资料；B为权威媒体、机构或平台；C为演示、合成或间接代理；D为研究者假设。只有A/B级记录参与事实异常筛查；C/D级不触发事实异常。

## 4. 自动筛查规则

1. **同口径多源冲突**：同一指标、地区、行业、期次、单位和范围出现不同来源数值，且差异超过筛查阈值，生成口径冲突候选。系统不自动选值。
2. **时间序列异常候选**：同一指标至少5期，比较相邻期变化与历史变化的中位数/MAD；偏离阈值时提示复核。它只用于排序，不是统计显著性检验。
3. **跨指标背离**：对同一地区、期次、单位和范围的可比指标，识别工业产出与投资等指标方向不同的情形。
4. **行业横向差异**：同一指标至少三个行业、同一地区和期次下出现较大差距时，生成描述性分化候选。
5. **调查跨期变化**：同一题项、总体和抽样框的多个调查批次出现数值变化时，提示比较；不自动计算显著性。
6. **调查汇总**：保留样本量、总体、抽样框、聚合方式和缺失率。样本量大不自动代表样本有代表性；未证明概率抽样、覆盖与权重前，不外推全县。

内置的公开问题候选包括：工业与投资背离、重点行业内部差异、投资目标与实际增速差、公开口径冲突、企业采购/项目兑现等数据缺口、企业调查盲区。

## 5. 每个问题候选必须包含

- 触发它的可追溯观察；
- 竞争性解释，而非单一结论；
- 反证条件/何时改判；
- 下一项最有价值的数据；
- 证据等级和统计口径边界。

新增数据不会直接改写GDP基准、模型参数或2032年1:5:4产业布局目标。只有经过口径审核、实体归并、版本确认和人工批准后，才应进入模型适配层。

## 6. 当前限制

- 浏览器本地保存，不跨设备同步；清理浏览器数据可能丢失。
- 尚无部门API、账号权限、多人审计或自动更新。
- 不对导入数据做因果识别；不自动更新模拟结果。
- 时间序列筛查阈值是明确的研究者规则，需按指标类型、季节性和数据频率校准。
- 目前没有新上传的企业调查数据；演示页面显示的是既有公开观察与数据缺口，不会假装已获得部门数据。
