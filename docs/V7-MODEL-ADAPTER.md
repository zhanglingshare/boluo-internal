# V7 数据审核与模型适配协议

## 1. 目的与边界

V7将V6的匿名汇总观察接到研究变量目录，并提供人工审核、变量映射和证据关联的情景比较。

它不是自动参数估计器，也不是部门数据平台。当前工作台不连接发改局数据库、不上传CSV、不跨设备同步。导入记录、审核状态、映射记录和情景提案都保存在当前浏览器的localStorage。localStorage不是加密数据库，不能存放个人答卷、企业交易明细、商业秘密或可识别信息。

## 2. 数据来源

适配台内置两条仓库已记录的2025公开基准：
- 规上工业增加值增速：8.7%，映射到“工业增加值增速”。
- 固定资产投资增速：-18.8%，映射到“固定资产投资增速”。

这两条记录是B级公开统计演示数据。其余数据来自V6本机CSV导入。V6 CSV仅接受指标汇总和匿名问卷汇总，不接受个人级数据。

## 3. 映射准入

每条观察必须核对：
- 变量定义及指标名称；
- 单位与数值范围；
- 期次、地区、行业；
- 统计范围、分母与来源；
- 证据等级；
- 调查汇总的总体、抽样框、样本量、聚合方法和缺失率。

自动映射只在指标名称与单位同时命中词典时提出建议。人工映射必须填写至少12个字的口径对应说明。映射必须先保存，之后才能申请批准。

只有A/B级可核验来源可批准进入事实证据层。C级代理、演示数据和D级研究者假设不能批准为事实。批准表示“这条观察可作为当前研究变量的证据”，不表示其已经具有因果识别资格。

以下复合变量不能由一条标量记录单独批准：
- 三次产业结构：需要同版本、同口径的三个产业分项；
- 供应链网络：需要主体、关系、方向、金额和去重规则；
- PLS/SEM路径：问卷均值不能替代估计路径系数；
- 农业账期错配：需要回款、付款、金额等多维记录。

同一变量、同地区、同期次、同范围出现多个来源版本时，系统不自动平均、不自动覆盖。审核者必须在映射说明中记录核验和版本取舍依据。

## 4. 变量到模型参数：禁止偷换

当前引擎的五个旋钮（agriculture、manufacturing、services、talent、project_delay）是情景冲击强度，范围受引擎约束；它们不是可以从一条统计指标直接读取的实测值。

| 模型条件 | 可关联的研究变量 | 当前可做 | 直接校准所缺 |
|---|---|---|---|
| manufacturing | industrial | 关联工业状态证据，手动情景压测 | 分行业产量、订单、产能利用率、价格和投产批次 |
| project_delay | project_delivery、investment | 关联项目与投资背景，手动情景压测 | 项目到期分母、计划/实际投产日期、项目规模和滞后 |
| services | local_service | 关联本地服务采购证据 | 采购金额、供应商属地、增加值率、用途和跨期交易 |
| talent | talent | 关联岗位缺口证据 | 技能分类、空缺时长、招聘/离职、培训和产能兑现 |
| agriculture | cash | 关联账期与农业价值链背景 | 同批次产量、价格、成本、损耗、回款和农户收入 |

**当前直接参数校准资格为0/5。** 任何参数直接校准，至少需要明确的测量方程、基准期、转换规则、滞后结构、估计样本和独立验证。V7不自动推断这些关系。

## 5. 证据关联的手动情景实验

当某参数关联了至少一条已批准证据，用户可以：
1. 选择一个模型条件；
2. 手动设定候选情景值；
3. 写明至少15个字的解释，说明证据如何影响本次情景假设；
4. 在相同随机种子、相同抽样次数和相同其余输入下并行运行原基准与候选情景；
5. 比较P10、P50、P90及模型条件命中频率；
6. 保存提案。

提案记录包含证据ID、变量、原始输入、候选输入、运行摘要、研究者解释、时间和“未应用”状态。提案只存在当前浏览器，不改变默认模型、官方基准或其他用户的实验状态。

输出仍是既有模型条件下的情景比较，不是现实概率、政策净效应或参数估计。用户手动选择的滑杆值不能包装成数据校准结果。

## 6. 后续正式接入所需

发改局真实使用前，需要另行建设：
- 部门身份认证与角色权限；
- 服务端安全存储、加密、备份和访问日志；
- 数据版本、修订、审批人和时间戳；
- 企业调查匿名化、抽样框和加权方案；
- 变量字典、单位转换和跨期可比规则；
- 模型参数测量方程、估计与独立验证；
- 正式基准发布、回滚和快照复现。

这些能力目前不在GitHub Pages本地工作台内。


## 7. 答辩式交互呈现
V7工作区采用五段式演示结构：研究命题、证据审核、变量映射、现场模型实验、研究结论与边界。默认每屏突出一个研究问题和一组图表，口径说明、证据限制和技术边界收进可展开区域。证据列表可点击切换审核对象；变量与模型条件可点击切换；参数滑杆可实时调整；运行后并排显示原基准与候选情景的抽样分布。全屏答辩模式隐藏外围工作区导航，支持键盘左右翻页和Esc退出。演示界面仍连接真实本地审核状态与计算引擎，不是静态PPT截图。
