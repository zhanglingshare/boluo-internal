# 内部版研发路线与验收

## P0（本仓库当前实现目标）
- 私有独立仓库；唯一可复现Demo；Python API与响应式界面。
- 条件驱动的三产增加值情景计算、分位数和结构图。
- 企业关系指标和探索性问卷路径模型实际计算。
- SPSS/SmartPLS分析包导出、结果回传与探索性对照。
- CSV/XLSX导入、快照留存、权限提醒与基础测试。

## P1（后续，未完成）
- 校准、比较并审核编程PLS与SmartPLS的估计等价性。
- 更细的行业与镇街结构、价格调整、行业分类映射。
- 规范抽样设计、问卷项目库、纵向数据质量检查。
- 研究模型准入与报告审查流程。
- 可选的安全访问网关与管理角色。

## P2（获得合法数据后）
- 由你确认具体数据授权、使用范围和敏感性。
- 审查观测单位、缺失、行业分类与时点。
- 用真实数据重新估计模型，不沿用Demo生成时的真值与参数。
- 模型间差异作为研究问题，不以简单平均掩盖分歧。
- 经人工确认后导出可以共享的聚合结果，公众V11仍保持独立。

## 不可妥协的测试
1. 同seed/同数据快照应得到一致结果。
2. 调整情景必须真正重新计算且允许偏离1:5:4。
3. 删除必需调查列必须拒绝分析。
4. 有真实数据时必须记录MIXED或REAL_UNVERIFIED，不能写成已核准。
5. 未经授权不能通过API取得已启用令牌保护的数据。
6. 专业软件没有实际输出时，不能生成假的“双轨一致”。
