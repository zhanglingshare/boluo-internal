## 一、研究任务：从增长叙事转向结构解释

**总问题**：为什么博罗GDP突破1000亿元、制造业显著扩张，却仍需要追问资本形成、生产性服务承接、区域收益留存、农业现金流、居民收入和环境约束之间的结构关系？

需要对照的四个解释层：
1. 宏观结构转型：产业增加值份额和数量的变化是否与技术、效率、就业质量变化一致？
2. 产业组织与区域网络：企业之间的投入关系是否能将制造业扩张传到本地研发、设计、检测、工业软件、物流与生活福利？
3. 增长生成机制：存量产能释放、项目投产时间差、外需、能源、价格与统计修订的作用机制能否相互区分？
4. 韧性与政策识别：哪些产业连接一旦受扰动最容易失效，哪些参数只是模型敏感而非真实可控？

**研究基本约束：**“没有证据就不能装作有证据”。缺少价格指数、县域企业间真实交易关系、分行业行业内价格、项目兑现率、对照单位和足够样本时，不应该报告看似精确的因果系数、最优政策或所谓成功概率。

## 二、数据基础：新增公开2025年行业细分、社会与财务信号

### 1. 2025五个已披露规上工业子行业

| 子行业 | 占规上工业增加值比例 | 2025年增速 | 可推断什么 |
|---|---:|---:|---|
| 电子设备制造 | 23.2% | +23.0% | 既有规模又有高增速 |
| 电气机械及器材 | 14.2% | +13.7% | 大体量且正向增长 |
| 橡胶塑料制品 | 9.6% | -4.2% | 体量不小但当年收缩 |
| 金属制品 | 8.2% | +11.1% | 中等体量的增势 |
| 电力热力生产供应 | 6.2% | +14.0% | 公用事业增加值增速较快 |

五项合计61.4%，**未列示行业38.6%不能随意补成“其它均稳定”**。份额是2025规模，增速是可比价增长；不能拿各项直接乘出官方行业GDP贡献。

企业规模结构：小微型企业占56.8%、增长9.7%；中型24.0%、增长4.8%；大型19.2%、增长10.8%。这能提出“增长是否由少数大企业主导”的竞争解释，但并不构成企业级网络证据。

产品物量：中成药-24.9%、涂料+16.2%、饮料+13.4%、锂离子电池-4.3%、电子元件+5.0%、印制电路板-0.1%等。产品单位不同，只可用各自同比方向和幅度比较，不能累加产量。

### 2. 同一年出现的方向不一致

- 规上工业增加值+8.7%，工业用电量+6.8%；但工业投资-12.7%，固定资产投资-18.8%。
- 2025房地产开发投资-47.6%，商品房销售面积-19.2%。
- 游客人次+11.7%，旅游综合收入+19.1%，但金融业增加值-3.7%、贷款余额-0.1%。
- 城镇居民人均可支配收入45,832元，名义增长3.5%；农村32,915元，名义增长6.2%。
- 2025城镇/农村收入比约1.392；公报给出比2020年增加的绝对额后，可倒推2020收入比约1.554。**仅可做描述比较，不可自动解释为“某项产业政策改善福利”。**
- 2025单位GDP能耗下降2.9%，工业用电增加6.8%。指标不同，不应直接推出能源转型已实现。

### 3. 2025计划目标与实绩对照

| 指标 | 县政府2025计划 | 2025公报实绩 | 增速差距 |
|---|---:|---:|---:|
| GDP不变价增速 | +7% | +5.5% | -1.5个百分点 |
| 规上工业增速 | 9%以上 | +8.7% | 与9%下限差-0.3个百分点 |
| 固定资产投资增速 | +5% | -18.8% | -23.8个百分点 |
| 社会消费品零售增速 | 5%以上 | +3.9% | 与5%下限差-1.1个百分点 |
| 一般公共预算收入增速 | +3% | 按可比口径+0.2% | 粗对照-2.8个百分点，但需先核对计划口径 |

**不要把目标差异称为政策净影响。** 项目/投资增速与工业增加值增速是不同统计机制，不能加减得出GDP贡献。

### 4. 公开证据版本冲突必须挂在前台

- 2025社零：296.99亿元、公报增长3.9%；2025政府计划文件引用2024社零366.66亿元。直接除得约-19.0%，与公报增长相反。存在基期/范围/修订等未核实解释。
- 2025地方一般公共预算收入95.27亿元，公报按可比口径增长0.2%；计划引用2024收入78.02亿元。不能跨版本相除。
- 2025高企数公报为686，2026年初媒体报道称710。无权将差额认定为企业增减。
- 2024初步GDP 952.24亿元，最终核实为970.87亿元；这是已明确的核算修订。2024最终分行业数仍需补证。

每个冲突应该具有：冲突的两个原始数、证据链接、可比口径警告、排除性解释、下一次验证动作。当前系统提供四张可切换冲突卡。

### 5. 价格和名义增长必须拆开

2025 GDP 1005.45亿元，2024 GDP最终核实970.87亿元。若按这两个版本的现价GDP机械计算，现价增幅约**3.56%**。公布的2025不变价实际增速为**5.5%**。两者之比隐含总量价格变化近似**-1.84%**。这一近似不是官方GDP平减指数，仍须复核可比价格指数、核算修订及基期细节。

2030现价GDP对照1600亿元，以2025年1005.45亿元为基准，算术上需要约**9.74%名义复合年增长**。绝不能直接和2025实际增速5.5%作同口径比较。

## 三、理论识别：博士级不是“谁都上算法”

必须建立可证伪的竞争性机制：

**H1 存量产能 vs 投资时滞 vs 外需**：同一年工业增长、投资下滑是否因为旧项目进入产出阶段？需要项目分批兑现、行业开工率、订单、价格。

**H2 生产性服务本地承接 vs 跨县购买**：工业增长是否自动形成本地研发检测和软件增长？需要采购地、合同结算地、企业服务占比。

**H3 产业扩张与居民福利**：城乡收入差异背后的工资、就业、户籍和生活成本变化如何区分？需要岗位结构、工资中位数、CPI、通勤负担。

**H4 环境效率与组成效应**：单位GDP能耗下降，是单位企业技术效率提高，还是行业结构变化、外部采购或统计口径变化？需要行业物量与能耗分解。

每个研究题必须含：已观察信号、三个以上竞争解释、区别性证据与排除性检验。目前仅形成研究设计，不声称识别完毕。

## 四、结构网络：从一级断点到二阶关系传播

演示网络保留既有合成500主体、680有向边，服务采购边从制造企业指向服务供应主体，农业供货边从农业主体指向制造主体。

可移除0、3、5、10、20、30个合成服务主体，策略为“高采购额先移除”或“固定种子随机”。由真实合成边集统计：
- 失联服务采购边和合成金额；
- 失去至少一条服务关系的制造主体数量；
- 达到指定1条或2条服务损失阈值的制造主体；
- 这些受影响制造主体上游被标记的农业供应主体数。

这里不将受损关系转换为GDP损失，不生成实际企业名称或“确定会停产”的结论。二阶传播是拓扑实验，不是产业投入产出因果计算。

## 五、模型不确定性：至少要分为两层

1. **模型内随机性**：给定增长率、扰动方差和相关系数，蒙特卡洛输出P10、P50、P90。这是条件分布，而不是现实概率。
2. **参数知识不足**：将三个产业年名义增长假设同时设为基准±1.5个百分点，重新算无随机扰动的确定性结果。区间是人为设定的边界，不是统计置信区间。

必须并排画两条分布带，而不能把“参数不知道”和“随机波动”合在一起吹嘘高精度概率。

### Morris型全局敏感度（已实现演示）

固定随机种子生成32条参数轨迹，在允许参数域中用0.25强度步长逐项扰动五个变量，计算每个变量的元素效应。展示其平均绝对值μ*与分散度σ。

这回答的是“我们的模型对哪些假设更敏感”，不是“哪些政策在现实中因果效应最大”。与欧盟JRC不确定性和敏感性方法原则相容，但不意味着已达到成熟的参数后验或经验验证。

## 六、方法准入门槛（研究失败也要诚实输出）

| 方法 | 当前状态 | 失败原因及下一步条件 |
|---|---|---|
| 历史统计结构分析 | 有限可用 | 已有2020–2025部门数据；需统一2024核算修订版本 |
| 规上工业内部异质性 | 可描述 | 有2025年五行业，但欠缺更多行业、长期细分面板 |
| 时间序列计量/结构断点 | 不准作强识别 | 宏观年份太短、修订和价格问题严重 |
| Shift-share行业外部比较 | 未实现实证 | 缺可比省市同类细分行业增速及同期权重 |
| DEA/效率前沿 | 暂不实施 | 缺足够可比单位、投产要素及产出指标 |
| DiD / IV因果识别 | 暂不实施 | 没有明确对照组、外生冲击、平行趋势/排除条件 |
| 真实SNA | 暂不实施 | 合成网络并非真实采购网络；需合法采集主体关系 |
| 探索性PLS | 已做合成演示 | 尚未通过SmartPLS逐项验证或区分效度、预测能力完整质量门 |
| 蒙特卡洛与双因子压力面 | 已做条件演示 | 缺外部参数估计、经验概率与反事实识别 |
| 多模型结果对照 | 方法可运行 | 模型分歧只是不同假设结果，不是统计模型平均 |
| Morris全局筛查 | 已做条件演示 | 解释的是模型对研究者选定参数域的敏感度 |
| 用户自定义数据导入导出 | 明确后置 | 按用户要求，当前在线研究无需此功能 |

## 九、最终研发红线

不伪造镇级统计，不将营业收入与增加值混算，不将合成关系图冒充真实产业网络，不将路径相关解释为GDP因果效应，不声称缺乏验证的2030概率是可靠预报，不将预设结构比例称为已验证最优解。公开统计异动和冲突应优先查证，而非按模型期望“自动纠偏”。

**当前交付定位：内容显著扩展的博士研究导向型交互实验室；不是已完成并经同行评议的顶级博士研究成果。**

## 十、V3新增测量模型诊断

探索性合成问卷在原Alpha、AVE、路径和Bootstrap之外，还计算：
- HTMT：跨构念指标相关绝对值的均值除以各构念内部指标相关绝对值均值的几何平均，用于考察构念区分效度；不能用单一经验阈值直接宣布量表通过验证。
- 经营表现的两个前因构念VIF：在双解释构念结构中根据其相关系数计算，不能代表完整多构念、指标级共线性检验。
- 80/20合成样本留出预测对照：仅使用构念题项均分，训练集拟合含截距的线性回归，测试集计算RMSE并同训练均值预测基准比较。这是**普通线性模型的简化留出基准**，不是SmartPLS PLSpredict、Q²predict的正式指标级计算，更不是该PLS模型在真实数据上的预测有效性认证。

方法参考：
- Henseler, Ringle & Sarstedt (2015), HTMT判别效度：https://doi.org/10.1007/s11747-014-0403-8
- Shmueli et al. (2019), PLSpredict样本外预测指南：https://doi.org/10.1108/ejm-02-2019-0189
