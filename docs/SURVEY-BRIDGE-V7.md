# 博罗内部版 V7：公开信号 × 合成情景 × 未来真实问卷的可运行闭环

日期：2026-11-16
实际页面：https://zhanglingshare.github.io/boluo-internal/#survey
实现：survey-evidence-v1.js、survey-bridge-v1.js、survey-bridge-ui-v1.js、presentation-v6.js、lab.js。
独立仓库：zhanglingshare/boluo-internal。未修改博罗公众版及惠东项目。

## 一、现在可运行什么

1. 选择四类主题：制造与经营、旅游消费、人才就业、农业乡村。
2. 从登记在册的公开记录中看到原始信号、时间、来源链接与原始信源个数。同一公报转载或同源多个指标不当成独立问卷。
3. 选择两种竞争解释（扩张/摩擦），拖动人为设定的情景冲击强度（-1~1）。
4. 在三个演示群体中按固定种子生成每组120份**合成响应**，显示五等级分布、组均值及人为设定的敏感性范围；这些回答均不是调查结果，也没有基于公开信号估计倾向平均值。为了可重复，公开了固定随机种子与教学性质的生成机制。
5. 用户必须亲手点击“把此情景放进风洞”，系统才把这个**假设**投射到对应风洞参数：制造→manufacturing，旅游→services，人才→talent，农业→agriculture。不会把媒体数据自动变成GDP增长率。
6. 深入研究仍在同一页面的折叠区，原有V2—V5的PLS合成演示、测量统计、竞争假说、二阶网络、Morris筛查和风洞都保持；没有删除旧13张原型。

注意：0条媒体信息的主题同样能做纯假设演示，但更不能宣称它代表该群体。当前制造经营2条观测共用同一统计公报、旅游2条公开材料涉及不同性质的观察；人才、农业尚未入库具体公开信号。

## 二、为什么模拟问卷不等于OSINT校准

- 真实公开证据只用于说明*已经观察到了哪些迹象*及其竞争解释，**尚不用于估计五点量表的群体均值**。
- 生成的360份合成回答是给用户测试“扩张/摩擦假设会产生怎样的群体差异”而非研究者已采集的360份问卷。
- 合成均值与±1.05人为范围仅是模型敏感性示意，**不是统计置信区间**，也不能当作未来真人分数的贝叶斯先验。
- OSINT与真人问卷的真实预测关系需要同一总体、同一题项、同一时间与独立验证才有资格估计。

## 三、未来真人问卷：匿名汇总数据接口

当前同源文件：data/survey-summary.json

它现在显式标为：

\`\`\`json
{
  "schema_version": "1.0",
  "status": "pending",
  "updated_at": null,
  "datasets": []
}
\`\`\`

将来调查经过核验与匿名汇总后，可更新该JSON，状态改为\`verified\`，并写入数据集。前端已设计在页面加载时按同源地址获取此JSON；发布后无需重写网页即可启用初步描述性对照。

必需字段见文件中的example_schema（示意，不是实际回答）及survey-bridge-v1.js中的validateAggregate：

- topic：industry / tourism / talent / agriculture；
- item_id：和已冻结的研究题项一致，如industry对应business_outlook；
- scale_min=1、scale_max=5；需要明示受访者量表题项与语义锚点；
- fieldwork_start、fieldwork_end：调查实施窗口；
- population、sampling_frame、sampling_method：目标总体、覆盖范围、抽样与加权说明；
- groups：按已注册分群ID提交的匿名group aggregate，包含n、mean、weight及可选置信区间。

**不得把个人姓名、手机号、身份证、IP、设备ID、原始问卷答案或者能重识别到某个人的群体小样本公开到这个仓库。** 群体过小的数据必须在后端抑制或合并。当前数据文件只含状态和格式示例，没有实际受访者。

页面只会：
- 校验版本、主题、题项、1–5尺度、调查时间、样本量、分群；
- 在收到有来源的汇总时，展示真实均值、分群对照，以及与预先冻结的合成情景之间的描述性偏差；
- 根据偏差方向提示“哪些旧假设值得查证”；
- 保持旧版合成基准不变，不自动凭单次问卷改写任何OSINT信号权重或经济政策模型。

**这不是统计模型完成校准**：真正的代理映射、贝叶斯动态更新和预测区间，至少需要在未来用真实问卷区分训练期/验证期，对人群覆盖和选择性发声偏差做审查后才能激活。

## 四、研发验收

- 所有四主题均可选择；
- 决定方向、情景冲击和随机种子后，同输入得到完全相同的合成分布；
- 三组响应每组120份，五等级计数守恒，真实问卷人数始终为零；
- 同源材料不会伪装成不同独立来源；
- 转到风洞仅由用户点击发生，参数仍处于引擎允许范围；
- 无问卷时正常运行、发生故障时保持pending；
- 合法匿名汇总可以得到**描述性对照**，非法题项/权重/范围被拦截；
- 所有传统页面和13张原型保留，测试覆盖新入口及原有计算。

## 五、未来更高级的研究

真实企业用工仍然是优先试点。可采集去重职位、岗位薪酬、招工持续时间、企业投产等公开信号，先冻结不使用问卷信息的代理预报；真人调查后按企业规模、行业和镇街分群比较。可逐步估计代理映射、用样本外检验推翻错误模型。

没有实际概率样本之前，不能承诺“代理评分±0.3是95%置信区间”，也不允许把模拟PLS系数称为实测企业因果效应。
